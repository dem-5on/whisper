LINUX DESKTOP SETUP

Set up dictation

Linux desktops handle global shortcuts differently, so Wicx does not silently claim a shortcut that may conflict with your system. Add this command in your desktop's Keyboard Shortcuts settings:

wicx toggle
  1. Open your desktop's Keyboard Shortcuts settings.
  2. Add a custom shortcut and choose a key combination you like.
  3. Use wicx toggle as its command.

This works with GNOME, KDE Plasma, Xfce, Cinnamon, and other desktops that support custom commands.
