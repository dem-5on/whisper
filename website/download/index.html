Install Whisper on Linux

The guided installer currently supports Debian/Ubuntu-based Linux running a GNOME Wayland desktop. Other distributions and desktop environments are not supported by this one-command installer yet.

Before you begin: setup needs internet access to install dependencies and download the local speech model. Whisper asks before installing system packages. Wayland may need a one-time keyboard-input permission setup for typing transcripts into other apps.

Guided setup

1

Open Terminal

Open the Terminal app from your Applications menu. You don’t need to download or unzip anything first if you use the guided command below.

2

Run the installer

Copy this command, paste it into Terminal, and press Enter. Read the prompts; it may ask for your computer password to install required system packages.

curl -fsSL https://raw.githubusercontent.com/dem-5on/whisper/main/install.sh | bash
3

Finish desktop setup

If the Whisper panel icon doesn’t appear, sign out of GNOME and sign back in. Check that the “Transcriber” extension is enabled in Extensions.

4

Try a transcription

Start recording from the panel or bind a keyboard shortcut. The first local-model startup downloads the model; after that, local transcription can work without internet.

If it transcribes but doesn’t type into your app

Wayland protects keyboard input. Whisper uses ydotool for typing, and your Linux distribution may require a one-time permission setup for its `ydotoold` service to access `/dev/uinput`. See the installation troubleshooting notes; only grant this to a user you trust.

Using another Linux setup? The app is open source, but the guided installer and desktop panel currently target GNOME on Wayland. See the source repository for the manual setup path.

Windows support is being planned

There isn’t a Windows installer yet. Whisper’s current desktop controls and audio integration are Linux-specific, so a Windows build needs its own implementation and testing before we can offer a reliable download.

Please don’t install the Linux bundle on Windows. Follow development at the Whisper project on GitHub.

macOS support is being planned

There isn’t a macOS installer yet. Audio capture, shortcuts, and focused-app text insertion need a native macOS implementation and testing before we can offer a reliable download.

Please don’t install the Linux bundle on macOS. Follow development at the Whisper project on GitHub.
